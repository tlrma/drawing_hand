# ✏️ Hand Doodle

## 사용 흐름

1. **검지로 그리기** - 허공에 원하는 그림 그리기
2. **그림 완성** - 엄지척 👍 제스처 또는 `SPACE` 키
3. **확대 연출** - 그림이 가운데에 크게 표시 (1.5초)
4. **자유롭게 돌아다님** - 작아진 그림이 화면에서 둥실둥실 이동
5. **반복** - 캔버스가 자동 초기화되어 또 그릴 수 있음

## 손동작 가이드

| 제스처 | 기능 |
|--------|------|
| ☝️ 검지만 펴기 | 펜 (그리기) |
| 🖐️ 손바닥 활짝 | 지우개 |
| ✊ 주먹 | 대기 (펜 떼기) |
| 👍 엄지척 | 그림 완성! |

## 키보드 단축키

| 키 | 기능 |
|----|------|
| `SPACE` | 그림 완성 (엄지척 대신) |
| `C` | 캔버스만 비우기 |
| `X` | 떠다니는 그림 모두 삭제 |
| `Q` | 종료 |

## 설치 & 실행

```bash
pip install -r requirements.txt
python main.py
```

## 핵심 동작 원리

1. **MediaPipe Hands**로 손가락 21개 관절 추적
2. **손가락 펴짐 패턴**으로 펜/지우개/대기 모드 분류
3. **흰색 캔버스**에 검지 끝 좌표를 따라 선 그리기
4. **엄지척 인식 시**:
   - 캔버스에서 그림 영역만 잘라내기 (bounding box)
   - 흰색 배경을 투명하게 변환 (BGRA 알파 채널)
   - 확대된 버전으로 1.5초 표시 후 작은 크기로 변환
5. **Doodle 객체**로 변환되어 랜덤 속도/방향으로 화면 이동
6. **회전 + 둥실거림 + 가장자리 튕김**으로 살아있는 느낌
